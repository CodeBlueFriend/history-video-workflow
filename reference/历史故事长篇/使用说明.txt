历史故事长篇｜工作流设计V5
更新日期：2026-10-28

交付性质
本包是更新后的工作流设计、目录模板、内容与审核规则、数据清单及Codex搭建任务书，不是已经实现的生产软件。空白模板没有真实稿件、图片、封面、音频或视频。审核状态均为未执行。
本次没有访问或修改你的电脑桌面。把压缩包解压到电脑的实际桌面后，应得到“桌面/历史故事长篇”。原有桌面同名项目应先备份后迁移，避免覆盖已有素材。

一、唯一项目根目录
根目录为实际桌面下的“历史故事长篇”。程序首次运行识别操作系统的真实桌面路径，不写死用户名，也不假定Windows桌面没有被OneDrive或其他设置重定向；无法识别时让用户选择现有项目根目录。解析结果保存到00_项目配置。
根目录包含公共配置、选题库、公共素材库、规则与模板、工作流程序，以及每集独立子文件夹。
每集直接放在根目录下，例如EP001_选题名、EP002_选题名。
创建新集时复制EP000_模板；不要把占位文字当作正式内容送去配音。

二、目标与分工
目标：以有吸引力且有依据的历史口播为核心，制作15—40分钟横屏长视频。
Codex负责：选题整理、资料整理、主张卡、提纲/稿件、分角色审核与返修、目录/版本管理、素材和封面方案、配音与剪辑交接包、检查报告。
用户负责：方向取舍、必要的争议裁决、已选音色的网页配音与试听、外部剪辑工具的导入操作和最终效果确认。
MiniMax网页负责：沿用已选声音生成旁白。此版不要求TTS API，不重新选音色。
AI智能剪辑工具负责：按实际支持能力完成图片编排、画面运动、字幕、音乐和合成导出。
第一版的本地程序重点做内容与项目管理，不默认自行编写视频渲染器。外部工具未确认前，交付通用素材包，不假称某份JSON能直接导入剪映或其他软件。

三、内容主流程
选题卡 → 广泛收集材料 → 来源与主张审核 → 事实底稿/争议表 → 提纲与叙事审核 → 分章初稿 → 独立事实审核和叙事审核 → 问题单 → 最小范围返修 → 复审 → 口播审核与文稿时长预估 → 内容和时长同时达标后锁稿。
审核机制参照既有写作Skill的“多角色、单总控、共享状态”“创作—审核—局部返修—复审—锁定”方法，具体写入03_规则与模板。本包没有安装或修改任何写作Skill。
内容是主要投入点。不要为了配图方便提前牺牲叙事，也不要为凑时长扩写重复信息。

四、资料范围
正史、编年史、实录、地方志、谱牒、档案、碑刻、考古材料、诗文书信、笔记野史、轶闻、传说、演义、现代学术和通俗文章都可入库。
体裁不等于可靠程度。正史也须核对记载与立场，野史也可以保留有价值线索；小说和传说不作为证明事件发生的独立史实证据。
不设置固定正史/野史比例。根据本集核心问题和证据条件选择材料。
关键结论、时间、人名、原话及重要因果以主张卡连接来源。多个网站转引同一本书不算多方独立互证。
来源缺失时先补证，无法补证可删除、归因表述或降低结论强度。不得让“AI再次说了一遍”充当核实。

五、锁稿后的制作
1. 先依据二创后的完整口播稿预估时长，审核达标再锁稿；随后依据同一版本并行准备少量代表场景背景图、封面和MiniMax网页文本包。
2. 文本包按章节和当前网页输入限制生成，不假定网页能一次输入整集。
3. 用户在网页生成音频、试听、下载，再明确映射到A001等任务。原文件不覆盖。
4. 画面定位为少量横屏背景图，低频切换。30分钟内部起步参数为正文6张，参考范围4—8张，可调整，封面另算。图片数量不按章节数、旁白段落或人物出场自动增加。一张图只对应一个代表性场景，可伴随较长讲述，避免误导性的跨人物/跨时代复用。图片默认保持自然缓慢运动；仅在安全运动空间用尽、旁白未结束且无合理换画点时允许记录在案的静止。
5. 封面独立入库：参考图、无字底图、标题文字方案、可编辑文件（工具支持时）、导出封面。封面承诺必须与正文一致。
6. 准备AI剪辑交接包：锁稿、确认旁白、编号图片、场景顺序、封面、字幕状态、剪辑要求和素材来源。
7. 外部工具用已有旁白作为主音轨，不改写文稿、不替换音色、不因“智能去停顿”破坏评书气口。能力不足时明确报告缺口。
8. 导入网页音频后实测旁白时长，并核对成片总时长；偏离目标先修改有依据的正文，再复审和重配受影响片段。预览核对原稿、音频、字幕、画面、封面和时长，通过后输出最终视频。

六、每集目录
00_项目记录：版本、状态、任务、验收。
01_资料与事实底稿：来源、主张卡、时间线、人物关系、争议与反证。
02_故事文稿：选题卡、大纲、初稿、定稿、段落和读音修正。
03_审核记录：问题单、证据、分数、修改、复审、锁稿。
04_素材：图片、音频、封面、音乐与音效。
05_AI剪辑交接包：普通文件格式的输入素材和制作说明。
06_剪辑工程：工具支持的工程文件；若为云工程，记录项目链接和参数，同时保留本地输入素材。
07_成片：预览视频、最终MP4和最终封面。
08_发布与复盘：标题、简介、参考资料、AI情境说明、工时及发布后数据。
09_运行日志：失败、恢复和变更记录。
公共素材用于制作时，在本集保存实际使用副本和来源快照，使每集可以独立搬动与归档。

七、审核与状态
稿件状态：NEW → RESEARCHING → EVIDENCE_REVIEW → OUTLINE_REVIEW → DRAFTING → REVIEWING → REVISING → SCRIPT_LOCKED。
制作分支分别记录图片、封面、音频的状态，不因等待音频阻塞其他准备。
交付状态：WAITING_WEB_AUDIO → AUDIO_VERIFIED → EDIT_HANDOFF_READY → WAITING_AI_EDIT → PREVIEW_REVIEW → FINAL_ACCEPTED。
BLOCKED表示有未解决的必要条件；不能以“文件已存在”冒充审核通过。
锁稿必须有对应版本和复审记录。只替换封面，不重做配音；修改核心文稿要进行影响分析，更新受影响的配音、字幕、封面和交接包。改动已由用户锁定的核心观点时，先给出影响说明并确认重开版本。

八、第一轮实施
先制作2—3分钟小样，验证网页配音交接、素材和封面入库、AI剪辑、字幕复查与文件归档，再扩展到30分钟。
小样既验证工具，也验证“故事是否听得进去”。未通过内容审核，不进入整集配音和批量生图。
运行程序尚待按04_工作流程序/给Codex的搭建任务书.txt实施。

九、本次细化的核心规则
正文低图量；提示词只写一个真实对应的代表场景；资料二创后全篇连贯复审；先按口播稿预估时长、再按配音和成片实测验收。详细见03_规则与模板新增两份规范。

V5新增剪辑规则：默认自然缓慢运动，源图与镜头段分开；静止必须记录原因；加入构图与动势匹配、语义落点、硬切/短叠化/声音桥、重影与转场重叠计时检查。所有参数为未实测起始值。详见完整主设计及图片运动与自然转场规范。

V5新增：每集05_AI剪辑交接包/剪辑文档保存独立Word与TXT执行文档、素材对应表、审核修改记录和历史版本。当前提供空白模板，真实剧集剪辑文档在锁稿与配音验收后生成并持续回填，作为最终交付的一部分。
