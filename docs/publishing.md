# 发布文案包

每集锁稿后建立发布文案草稿，交付前完成文案编辑。发布标题使用本集视频的完整标题，优先读取 `publication.title`，再读取稿件标题。可选的吸引句放在 `subtitle`，用于简介首行，不拼接或替换标题。

程序只生成本地文件，不登录或发布，也不保证审核、收益资格或播放量。实际上传限制、标题长度、原创和AI标识，以发布时本账号页面为准。标题太长时保留全文供使用者决定，不自动截断。

## 使用

```sh
# 锁稿时自动建立草稿；也可手动生成或复用已编辑文案
./scripts/history-workflow publication-package EP编号_本集文件夹

# 编辑JSON后，生成合并的发布资料及封面目录
./scripts/history-workflow publication-package EP编号_本集文件夹 --file /绝对路径/文案.json

# 发布或交付前核对输入版本与文件哈希
./scripts/history-workflow publication-check EP编号_本集文件夹
```

JSON字段示例（示例仅说明字段）：

```json
{
  "title": "与视频完全一致的完整标题",
  "subtitle": "从本集情节提出一句悬念，放在简介首行。",
  "subtitle_options": ["可选吸引句一", "可选吸引句二"],
  "body": "由锁定口播稿提炼的背景、人物关系和悬念。",
  "short_body": "短简介。",
  "tags": ["历史故事"],
  "pinned_comment": "围绕本集情节的问题。",
  "content_note": "本集来源性质、必要限定和实际使用的情境重构、AI素材说明。"
}
```

没有文案输入时，程序建立 `DRAFT_NEEDS_COPY` 草稿，不凭空编造历史内容或AI使用情况。创作助手应从锁稿和来源记录提炼正文、短简介及内容说明；三项齐全时标记 `COPY_READY_FOR_PLATFORM_REVIEW`。这个状态只表示字段已准备，不代表事实审核或成片最终验收通过。

默认在 `08_发布包/历史版本/` 中保存一份`发布资料汇总.md`和结构化`发布文案.json`，审核通过且标题一致的封面统一放在`封面/`。汇总覆盖抖音、B站、西瓜视频、今日头条、微信视频号、快手、YouTube、小红书、支付宝、拼多多。主副标题、正文、标签和来源依据按平台集中，代替旧版逐平台TXT；旧版本保留。通过`00_项目配置/发布文案配置.json`选择平台及封面比例。

标签先依据锁稿和账号定位，再匹配本地每周热点快照。缺失、过期、无关或第三方未核实线索不会直接作为热门话题采用。快照和规则配置变化会使旧包过期。详见[标签与每周流程](platform-tags.md)和[推荐规则与来源](platform-recommendations.md)。

统一发布资料也包含[各平台收益计划与参与路径](platform-monetization.md)。读取`00_项目配置/平台收益计划索引.json`，保留公开资料日期、入口、条件、待办及证据来源；本账号未核验时保持`NOT_VERIFIED`，不推算收入。索引缺失或超过7天提示重新检索，索引变化使旧包过期。该提示不阻断本地资料准备，也不证明可以上架或计收益。

视频标题修改后，旧包立即过期；重新生成会同步全部平台标题并保留文案供检查。稿件变化后，旧文案不会自动沿用，需重新提炼。手工修改生成文件会导致哈希检查失败，应编辑输入JSON后重新生成。`deliver` 只交付通过当前版本检查的发布包。

## 编写与核验

先交代人物处境，再提出本集能兑现的悬念。不把未经查实的供词写成事实，也不在稿件没有答案时承诺揭秘动机。资料性质和情境重构放在发布说明里，封面仍只显示主标题及已有副标题。

烧录字幕与独立SRT应逐条核对断句和时段，仅比较全文相同不够。外部编辑器的SRT若采用不同分段，以当前实际渲染的字幕卡及帧时轴重建SRT，保留原件和修正记录，并核对相邻字幕边界。

剪辑交付前也应检查叠化重叠的实际帧数。变速和取整后，淡入不得超过对应的重叠区；检查前图结束前后相邻帧，避免出现单帧变暗。

记录须区分字幕/OCR比对、音轨波形比对、抽帧、正常速度通看与人工听审。工具不提供可听声音或连续视频流时，后两项保留未完成，不能用自动检查代填通过。

视频最终验收后增加[专项文章改写](toutiao-article.md)。已完成的文字版在publication-package时复制进同一发布包的今日头条文字版文件夹，提供完整Markdown、排版HTML和JSON；发布资料汇总中显示文章状态和手动上传方式。文章变化会使旧发布包过期。视频简介仍用于视频投稿，文字版用于文章投稿；当前不执行自动上传。
