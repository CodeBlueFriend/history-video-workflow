# 完结后的今日头条文字版

每集正式视频完成最终验收后，增加一项专项工作：把锁定故事改写成适合今日头条阅读的完整文章，排好段落和小标题，与该集发布资料一起交付。视频简介仍用于视频投稿，文字版用于文章投稿，两者分别保存。

## 触发与状态

`accept`完成视频验收时自动建立文字版任务，输出改写依据包。配置在`00_项目配置/今日头条文字版配置.json`，默认开启。样片和测试集不自动建立任务。

任务必须基于当前定稿、来源记录和视频标题。由创作助手阅读全文后改写、核对和执行Humanizer检查，再导入文章输入JSON。CLI负责建任务、验证版本和排版，不会把未经改写的口播稿或空白模板标成文章成稿。

尚无文章时是`NEEDS_ADAPTATION`；文章已核对、视频仍待复审时是`ARTICLE_READY_VIDEO_REVIEW_PENDING`；文章与当前视频版本一致且视频验收通过后是`READY_FOR_MANUAL_UPLOAD`。文字版完成不改变视频听审、通看或验收状态，也不代表已发布。

如完结前已有审核通过的文字版，视频验收后会复用内容并重新打包，保留旧版。修改定稿、来源或主标题后必须重新核对文章；修改排版配置后重新生成导出。视频完结后，创作助手应继续处理文字版任务，完成后再运行统一发布包生成与交付。

## 改写规则

文章先交代时代、人物关系及眼前的难题，再推进事件。去掉“今天要说”“咱们把时间拨回”等口播提示及听觉重复，保留故事的起因、转折和结局；不把视频简介扩充几句充当全文。

正文采用短段落和有内容的小标题，适合手机阅读。完整标题沿用视频标题，吸引句单列。正文以叙事为主，资料说明放在文末；刑讯供词未查实、笔记记载性质等影响理解的限定仍在相关情节中交代，不因改成文章就把推演或二创坐实。

可复用本集已经审核的通用封面。文章正文暂不自动插图，也不把封面内的字当作文章内容；需要插图时先确认配图位置和含义，沿用本集素材权利记录。

## 交付与排版

文字版历史包保存在`08_发布包/今日头条文字版/历史版本/`。运行`publication-package`后，当前有效文字版会复制进统一发布包的`今日头条文字版/`，与通用封面、各平台标题文案和标签放在一起。文字版正文单列，视频发布文案仍合并在发布资料汇总内。

交付三个文件：

- `今日头条文字版.md`：完整文章，含标题、分节、内容说明和参考资料。
- `今日头条文字版.html`：本地排版预览。默认正文18px、行高1.9、最大宽度760px，小屏自动调整。
- `文章数据.json`：结构化标题、导语、分节段落、标签、来源编号、审核、版本及正文HTML，为后续上传适配器保留数据。

手动上传时用浏览器打开HTML，分别点击“复制标题”和“复制排版正文”，粘贴到自己的文章发布页；复制按钮受浏览器限制时可选中文字手动复制。正文复制不包含预览工具栏或重复的完整标题。平台可能重新处理粘贴的样式，上传后检查标题、小标题、段落、内容说明及封面。

首次发布、原创或AI内容标识等选项，由使用者根据实际创作情况及账号发布页填写，程序不代为声明。当前文章数据中的上传状态始终为`NOT_UPLOADED`。

## 命令

```sh
# 读取锁稿和来源，供创作助手专项改写
./scripts/history-workflow article-packet EP编号_集名

# 尚无文章时建立任务；已有有效内容时重新排版
./scripts/history-workflow article-package EP编号_集名

# 导入已经审核的结构化文章
./scripts/history-workflow article-package EP编号_集名 --file /绝对路径/文章输入.json
./scripts/history-workflow article-check EP编号_集名

# 把文章及封面、各平台文案和标签汇总交付
./scripts/history-workflow publication-package EP编号_集名
./scripts/history-workflow publication-check EP编号_集名
./scripts/history-workflow deliver EP编号_集名
```

输入JSON包含`basis_hash`、`title`、`subtitle`、`lead`（段落数组）、`sections`（每节有heading和paragraphs）、`content_note`、`source_ids`、`tags`和`review`。`basis_hash`必须使用当前article-packet返回值；审核应记录实际执行者、依据及faithful、readable、uncertainty_preserved、humanizer检查。

后续自动上传可读取同一份结构化数据，另接经过验证的账号认证、草稿上传、图片上传、预览确认、发布回执和失败重试流程。当前配置`automatic_enabled`为false，未实现自动上传或点击发布，不把本地打包称作平台草稿。

规范参考：[头条号2024年12月17日发布的创作规则升级公告](https://www.toutiao.com/article/7449248317823566346/)将排版和逻辑混乱等列为低质格式示例。本项目的字号、行高及导出格式为本地排版设计，当前账号权益与平台规则仍以发布页为准，不据此代为声明首发。
