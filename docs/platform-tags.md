# 视频标签与每周平台热点库

默认平台为抖音、B站、西瓜视频、今日头条、微信视频号、快手、YouTube、小红书、支付宝、拼多多。西瓜和今日头条分别出文案。百家号仅保留旧配置兼容，不在默认平台中。

每集使用已锁定的口播稿及当前视频标题分析人物、时代、事件和故事主题。先按账号长期定位取固定标签，再用内容匹配词补充本集标签，最后检索本地热点库。没有相关热点时直接使用内容标签，不用热榜填满数量。

`00_项目配置/视频标签配置.json` 可自定义账号定位、固定标签、内容标签的匹配词、更新周期和标签数。默认历史说书，最多6个；这是项目工作参数，不是平台上限。新题材出现时，创作助手应补充适用的人物/时代/事件规则，或在发布文案的tags中提出本集候选；候选只有在标题/锁稿中直接命中时才会采用。程序按可核对的关键词筛选，输出命中的原稿词语和排除原因，不预测播放量。涉及隐含的情节关联时，创作助手先核对剧情，再填写原稿中实际出现的匹配词。

## 每周执行

已约定每周一上午9点（Asia/Shanghai）由当前对话的每周任务执行。项目自身CLI没有后台常驻爬虫；开源使用者需要在自己的调度环境配置同样的流程。

1. 读取本文件和推荐规则说明，使用agent-reach可用只读渠道及官方网页。逐平台查热门话题、与中文历史说书有关的趋势、官方活动和规则变更。不要把全站热榜当成历史赛道榜，也不要把商品榜当成内容榜。记录地区、语言、榜单统计窗口及检索范围。
2. 只有访问到的内容才能入库。每条保存原名、链接、来源类别、榜单/活动时间、访问时间、观测证据和内容匹配词。区分`HASHTAG`、`SEARCH_TREND`、`ACTIVITY`、`CONTENT_SAMPLE`；新闻标题和作品标题不是已经验证的话题。不得把旧榜单今天重新访问的时间当作新热点时间。
3. 用`examples/platform-trends-template.json`填写10个平台。失败也保留检索词、原因和状态：`OBSERVED`、`PARTIAL`、`UNAVAILABLE`、`NOT_FOUND`。需要登录或不可读取时保留缺口，不绕过验证码或读取浏览器Cookie，不自动购买接口。
4. 真正的话题`HASHTAG`还必须填写`trend_at`（实际榜单或活动时间）；有结束日期的填`valid_until`。官方链接必须属于对应平台允许的域名。第三方线索单独标识，不会直接当作可用热门话题。
5. 通过`trends-import`归档本地快照。每次留历史版，不覆盖旧证据；最新快照超过7天后不再作为当前热点。若更新失败应写失败快照，不能把旧结果的时间刷新成今天。
6. 从锁稿运行`tag-match`，检查每个采用/排除原因。仅官方已验证话题、内容直接相关、仍有效时进入热点候选；默认预留最多2个热点位置，优先保留账号内容身份，最终仍在发布页确认话题入口与活动资格。不得借历史剧情蹭无关的现实新闻。
7. 如有官方规则变化，更新`00_项目配置/平台推荐规则索引.json`及`docs/platform-recommendations.md`，保留原版。重新生成受影响的正式集发布包，递增版本，并复制到对应桌面交付目录的发布资料文件夹；不改视频、不发布、不自动提交Git。没有变化或没有适用的新匹配时保持安静；适用新话题、规则变化、执行失败或需要用户操作时通知。

## 命令

```sh
./scripts/history-workflow trends-import /绝对路径/真实检索快照.json
./scripts/history-workflow tag-match EP编号_集名
./scripts/history-workflow publication-package EP编号_集名
./scripts/history-workflow publication-check EP编号_集名
```

数据在`production/02_公共素材库/平台热点库/`本地保存，默认不随Git上传。每集发布包保存使用的完整快照分析、标签配置、规则出处及哈希。正文、标题、文案、封面、标签配置、热点快照或规则变化后旧包会过期，需要重新生成；编辑导出的文件也会触发完整性检查。

## 统一发布资料

`08_发布包/历史版本/v版本号/`下只有一份供阅读和复制的`发布资料汇总.md`，结构数据保存在`发布文案.json`，全部已审核且标题一致的封面放在`封面/`。不再生成十份内容重复的TXT。

汇总包含：完整视频标题、封面主副标题、可选简介吸引句、各平台正文、话题、标签依据及排除项、公开推荐原则、来源链接、封面选项和素材是否齐备。YouTube普通tags单列为无#的元数据字段，简介话题另列。文案和标签准备好不等于成片验收通过，也不证明账号已具备完整片上传资格。
