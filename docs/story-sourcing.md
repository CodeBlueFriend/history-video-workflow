# 每次启动阅读：素材检索与故事选题建议

这些是供使用者阅读的建议项，数量与题材可按项目调整，不是制作放行条件。程序每次正常执行命令时会在 stderr 显示建议；stdout 保留原命令的 JSON，便于脚本使用。`--help` 也包含建议，可在初始化前单独查看：

```sh
./scripts/history-workflow startup-guide
# 或使用 Python 入口：
.venv/bin/python -m history_workflow startup-guide
```

提示无需确认，不会自动发起联网检索、下载书籍或生成故事。创作助手启动新一轮内容生产时，也应先阅读本说明及工作区已有的内容选题偏好。

## 1. 从具体故事出发

优先选择带名人或与名人有明确关系的故事，从鲜为人知的细节、人物关系、具体遭遇和选择切入。名人可以是主角，也可以通过亲友、同乡、门客、对手或相关事件进入故事；这种关系应当影响情节。题材开放，不将人物生平或重大事件概述作为默认选题单位。

## 2. 扩大素材范围

同时检索正史与编年史、地方志与乡土志、笔记野史与杂史掌故、私人文集与书信、日记年谱、家谱碑传与墓志、公案判牍与档案、诗话词话、城市生活记录，以及志怪传奇和民间传说。

素材的体裁、可信程度和故事价值分别记录。不因正史无载就排除故事，也不因古书有所记载就直接认定为事实。

## 3. 用两条路径检索

- 从人物向外找：姓名、字号、官职、谥号、亲友、门客、任职地、贬谪地和居住地，结合繁简、异体及地名沿革查找。
- 从情节反查人物：书信、借贷、馈赠、失物、考试、诉讼、婚姻、疾病、夜访、求见、宴饮等，再核实故事与哪些名人有关。

记录书库入口、书名、编者、具体版本、卷次、叶码及影像页码。书目、搜索摘要、OCR文本、人工核对原页应分别标记，不能将“找到目录”登记为“已读全文”。

## 4. 建故事卡，再形成候选

每张故事卡建议包含：

| 字段 | 内容 |
|---|---|
| 核心故事 | 一句话梗概、开头、主角与名人的具体关系 |
| 情节推进 | 主角目标、阻碍、选择、代价、转折、悬念、结局 |
| 来源 | 书名、编者、版本、卷叶、影像定位、原文摘录与链接 |
| 记载性质 | 原始记载、作者转述、传闻、推测、二创；记录矛盾和转引关系 |
| 改编空间 | 可补充的场景、对白、动作和支线，拟改变的关键情节 |
| 制作判断 | 预计长度、资料缺口、查阅条件与复用条件 |

可先试采30—50张有出处的故事卡，筛为8—12条较强线索，最终给出约5个候选。这是建议规模，可以按资源调整，不是声称已完成的数量。

候选应展示：标题、关联名人、故事切口、人物困境与悬念、史料基础、拟二创范围及建议时长。使用者选择后可补充自己的想法，保存方式见[选题选择与个人想法](workflow-v5.md#候选选题选择与个人想法)。

## 5. 逐条判断记载，保留改编空间

判断作者距事件多远、是否亲历、信息来自谁、何时成书、版本是否改动、其他记载是否只是同源转抄。同一故事被多次转载，不等于多条独立证据。

没有正史旁证的逸闻仍可作为选题，以“某书记载”说明来源；传闻和志怪保留其叙事性质。二创可补场景、对白、动作和支线，创作记录应注明；改变关键事实时按改编处理，向观众恰当说明。

## 6. 按故事容量安排制作

15—40分钟围绕一个核心故事展开，可串联直接相关的小故事、人物关系和生活细节。按情节容量决定长度，不将短小逸闻硬拉成长篇。

有口播稿后运行 `preflight` / `run-start`，按有效字数估算视频时长。手动网页配音生成耗时和费用暂不计入。没有模型用量回执、单价或GPU测量时，实际算力成本保留未知；墙钟时间不等于算力消耗。

## 7. 书库起步入口

以下是2026-10-28检索时登记的资源。资源介绍或导航可读不代表所有书籍全文均开放；每次实际采用时核验访问及复用条件。

| 入口 | 检索方向 |
|---|---|
| [国家图书馆古籍数字资源导航](https://www.nlc.cn/pcab/zy/szzy/) | 地方志、家谱、宋人文集及古籍影像 |
| [马普所—哈佛燕京稀见地方志](https://www.mpiwg-berlin.mpg.de/research/projects/rare-local-gazetteers-collection) | 稀见方志全文及对应影像；项目全文标示CC BY-NC-SA 4.0 |
| [哈佛燕京数字化项目](https://guides.library.harvard.edu/c.php?g=310534&p=3767236) | 海外善本、地方志、丛书及文集 |
| [书格](https://www.shuge.org/) | 笔记、杂史、小说的古籍影像与版本介绍 |
| [识典古籍](https://www.shidianguji.com/) | 按人物及条目查找文本线索，核对具体版本 |
| [台湾华文电子书库](https://taiwanebook.ncl.edu.tw/z/search) | 民国旧书、掌故与地方文献 |
| [上海图书馆数字人文](https://www.library.sh.cn/service/service/11) | 家谱、人物关系及档案资源入口 |
| [东洋文库岩崎文库开放公告](https://toyo-bunko.or.jp/information/2625/) | 海外和汉古籍影像；按公告逐步发布 |

补充候选入口：[Kanripo](https://www.kanripo.org/)、[中国哲学书电子化计划书库](https://ctext.org/library.pl?if=gb)、[复旦地方志数据库](https://kz.fudan.edu.cn/dfz/)。上述三个入口在本轮分别出现403或超时，暂不记为已验证的全文获取渠道。

试读书目可从《朝野佥载》《北梦琐言》《酉阳杂俎》《归田录》《涑水记闻》《萍洲可谈》《铁围山丛谈》《鹤林玉露》《万历野获编》《客座赘语》《阅世编》《板桥杂记》《池北偶谈》《啸亭杂录》《履园丛话》《茶余客话》《清稗类钞》等开始。它们是候选书目，需继续核对版本与具体条目，不代表已全文入库或其中故事均已证实。

## 8. 开源与复用

开源仓库公开代码、使用说明和来源目录。第三方全文、扫描影像、现代校注和数据库导出数据按各自条件处理，不能因项目采用MIT许可证就一并视为MIT内容。查阅、下载、原文引用及画面使用分别记录。
