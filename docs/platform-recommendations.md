# 视频平台推荐规则与标签作用

核对日期：2026-10-29。此处整理公开原则；未找到的部分保留未知，不使用运营传言中的固定流量池、权重或万能标签公式。

|---|---|---|

| B站 | 官方创作课程建议准确填写内容标签，并按投稿分区查看活动标签；未公布本项目可用的固定推荐权重。 | [来源1](https://activity.hdslb.com/blackboard/static/20220413/3a39c8b7178bc50b4dc5d0700df76d20/lesson3.pdf) |
| 西瓜视频 | 算法备案公示覆盖西瓜和今日头条，描述以用户行为建模并进行排序、打散和干预；不能据此推出标签数量或播放保证。 | [来源1](https://beian.cac.gov.cn/api/static/fileUpload/principalOrithm/additional/user_9b84b02a-0c7f-4bd4-81f2-5cad879ad4ab_96ed08c8-0ed8-4ab5-b04d-46cccf4c00ab.pdf) |

| YouTube | 普通视频tags主要帮助纠正常见拼写问题，对发现的作用有限；标题、缩略图、简介更重要。推荐还结合观看/搜索历史和满意度等信号。普通tags与#hashtag应分别填写。 | [来源1](https://support.google.com/youtube/answer/146402?hl=en)、[来源2](https://support.google.com/youtube/answer/16089387?hl=en) |

| 拼多多 | 已找到官方创作入口，未核实一般历史说书视频的公开推荐细则和热门话题榜。不能用电商商品推荐或版权短剧激励规则代替。 | [来源1](https://live.yangkeduo.com/n-creator/live/home) |

标签选择应先准确描述内容，再看相关话题是否仍有效。历史说书可以保留稳定定位，但每集人物、事件和情节标签仍需按锁稿调整。项目默认最多选6个，是便于人工核对的工作参数，不是平台限制。

推荐标签不等于可发布资格。上传时仍要核对本账号的时长、标题长度、话题入口、原创及AI内容标识；封面比例按当前页面实际裁切选择。
