# 时长与正文画面资源规划

新正式集默认时长15至60分钟，上限3600秒。CLI的new、topic-select与Python入口统一从`00_项目配置/制作规划配置.json`读取默认值；可以在立项时明确选择更小的区间。已有集数的范围、图片和成片保留原版，不通过更改默认值冒称已重制。

新集创建时快照为`visual_policy`。`image-requirements 集名`查看本集规划；预算仍从锁稿字数和计划语速估算，不用上传音频长度代替。剪辑时的镜头对齐仍依据真实音频。

## 图片数量

正文图片基准提高到每分钟1.5张、最低12张。按整片总时长计算，15分钟约23张，30分钟45张，60分钟90张；片头片尾也计入总时长，临界值向上取整。四套封面另算。预算取字数规划数与镜头中实际独立源图数的较大值，少图计划不能压低启动预算，并显示当前还差多少张。

这是资源准备基准，不要求每40秒机械换图。根据场景、人物出场、动作和转折切换画面；情节密集时补图，节奏较缓时可延长使用。改裁切、加推拉或将同一图片拆成多个运动片段，都不计作新的源图。

## 关键情节必须有对应图片

锁稿后，由创作助手逐段判断哪些画面不可缺，建立镜头计划里的`critical_scenes`。至少覆盖：

- `SETTING`：开场环境及人物关系。
- `KEY_EVENT`：推动本集故事的核心事件。
- `TURNING_POINT`：冲突变化、关键选择或待遇差异。
- `OUTCOME`：结局及家人等相关人物承受的后果。

一个角色可有多项画面。列齐四种角色不代表已经找全关键情节，创作者仍须检查锁稿中的其他重要动作、人物和地点变化。程序只校验资源和映射，不声称自动理解了故事。

每项关键画面须有独立源图，图片段落映射要覆盖该情节，镜头表也要在对应段落实际使用该图片。只下载但未上时间轴的图片不能计为覆盖；一张通用背景不能同时顶替所有关键画面。普通氛围图可以合理复用。

镜头计划示例片段（示例不是本集真实素材）：

```json
{
  "critical_scenes": [
    {
      "id": "V001",
      "role": "KEY_EVENT",
      "description": "当前锁稿中的具体事件画面",
      "paragraphs": ["P008"],
      "reason": "这段发生关键动作，通用人物肖像无法表达",
      "image": "IMG008"
    }
  ]
}
```

这只是字段示例，完整计划仍需包含其他关键角色、原有shots及transitions字段。每项图片要完成来源、使用条件、身份、时代和构图审核，再核验实际画面与叙事一致。

## 少图与长图复核

少于数量基准时，计划须填写`image_density_exception`；同一源图连续超过120秒时，须填写`long_image_exception`。两者均要求reason、reviewer、evidence及accepted:true。复核必须真实执行，不能自动填写通过。关键画面缺失不能靠数量例外放行。

连续同图检查会合并相邻的同源图运动段，不能以拆段绕过。长图复核仍需检查实际运动、人物裁切、字幕遮挡及观看疲劳，参数记录不能代替通看。

新规则对正式集且规划时长至少5分钟的计划执行强制校验；样片和更短的测试跳过这部分长片门槛，原有素材与时间轴检查仍执行。旧集没有visual_policy快照时显示LEGACY_NOT_ADOPTED，保持原有验收依据；以后明确重制时再采用新快照并重新规划、审核和导出。
